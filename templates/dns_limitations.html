Synthetic training data

The classifier uses the Daumel DNS tunneling/exfiltration dataset. The author states it is synthetically generated and may not reflect real-world DNS traffic. Tool families (iodine, dnscat2, ozymandns, etc.) were inherited from that release — not selected independently by this project.

Length-only baseline

A Random Forest using only dns_domain_name_length already reaches about {% if length_baseline %}{{ '%.1f'|format(length_baseline * 100) }}{% else %}95.8{% endif %}% test accuracy on the same sample. The hybrid model largely refines a strong length/subdomain separation common in this synthetic corpus.

Leave-one-tool-out (malicious recall)

When one malicious generator is held out of training, recall on that tool often collapses. Mean holdout malicious recall across tools is about 31%.
