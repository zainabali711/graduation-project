About CyberScan

A multi-service detection workspace for URLs, domains, and DNS query names.

Project

CyberScan is a graduation project that combines three complementary services: an ML + VirusTotal URL Scanner, a WHOIS/network Domain Inspector, and an offline hybrid-ML DNS Query Scanner trained on synthetic query-name data. Together they help students and researchers explore lexical detection, enrichment lookups, and the limits of synthetic DNS datasets — with clear verdicts and honest caveats where needed.

How it works

Each service has its own pipeline.

URL Scanner

  1. Extract lexical + brand/DNS/SSL/WHOIS reputation features
  2. Classify with Random Forest + calibrated SVM; apply allowlist and 95% threshold
  3. Combine probabilities via Soft Voting
  4. Check reputation with VirusTotal and correct clear ML false positives

Domain Inspector

  1. Resolve the domain to an IP address
  2. Look up geolocation / organization signals
  3. Check SSL certificate status
  4. Surface WHOIS / registration details when available

DNS Query Scanner

  1. Extract 18 lexical features from the typed DNS query name
  2. Classify offline with a Soft Voting RF + SVM hybrid
  3. Report verdict, confidence, and generalization warnings
  4. Treat results as research signals — model trained on synthetic data (limitations)
