About CyberScan

Detection of Malicious DNS Queries Using Machine Learning Techniques.

Project

CyberScan classifies URLs as Malicious or Benign using lexical + reputation features, a Soft Voting ensemble of Random Forest and calibrated SVM, ML guards (allowlist / 95% threshold), and VirusTotal for final correction.

StudentZainab Ali Saleem Al-Hattali
UniversityArab Open University, Muscat
DepartmentComputer Science

How it works

  1. Extract lexical + brand/DNS/SSL/WHOIS reputation features
  2. Classify with Random Forest + calibrated SVM; apply allowlist and 95% threshold
  3. Combine probabilities via Soft Voting
  4. Check reputation with VirusTotal
  5. Correct ML false positives using engine consensus
